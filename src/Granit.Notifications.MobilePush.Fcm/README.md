# Granit.Notifications.MobilePush.Fcm

Firebase Cloud Messaging (FCM) provider for `Granit.Notifications.MobilePush`. Sends push notifications via FCM HTTP v1 API with automatic token invalidation cleanup.

Part of the [granit](https://gitlab.digitaldynamics.be/digital-dynamics/granit-dotnet) framework.

## Installation

```bash
dotnet add package Granit.Notifications.MobilePush.Fcm
```
