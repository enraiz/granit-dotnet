# Granit.Notifications.MobilePush.Sns

AWS SNS provider for `Granit.Notifications.MobilePush`. Registered as Keyed Service with key `"Sns"` for multi-provider resolution.

Part of the [granit](https://granit-fx.dev) framework.

## Installation

```bash
dotnet add package Granit.Notifications.MobilePush.Sns
```

## Dependencies

- `Granit.Notifications.MobilePush`
