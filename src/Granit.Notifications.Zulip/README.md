# Granit.Notifications.Zulip

Zulip notification channel for Granit.Notifications. Provides `IZulipSender` abstraction, `ZulipBotSender` implementation via Zulip Bot API (`POST /api/v1/messages`), and `ZulipNotificationChannel` with stream/topic routing.

Part of the [granit](https://granit-fx.dev) framework.

## Installation

```bash
dotnet add package Granit.Notifications.Zulip
```

## Dependencies

- `Granit.Notifications`
