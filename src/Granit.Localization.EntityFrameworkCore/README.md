# Granit.Localization.EntityFrameworkCore

EF Core implementation of ILocalizationOverrideStore for Granit.Localization. Persists translation overrides with ISO 27001 audit trail and multi-tenant isolation.

Part of the [granit](https://granit-fx.dev) framework.

## Installation

```bash
dotnet add package Granit.Localization.EntityFrameworkCore
```

## Dependencies

- `Granit.Localization`
- `Granit.Persistence`
