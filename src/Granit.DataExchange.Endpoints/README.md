# Granit.DataImport.Endpoints

Minimal API endpoints for the Granit data import pipeline. Exposes upload,
preview, mapping confirmation, async execution, dry-run, status, report, and
correction file download. Protected by the `DataImport.Admin` permission via
`GranitAuthorizationModule`.

Part of the [granit](https://gitlab.digitaldynamics.be/digital-dynamics/granit-dotnet) framework.

## Installation

```bash
dotnet add package Granit.DataImport.Endpoints
```
