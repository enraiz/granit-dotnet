# Granit.DocumentGeneration

Document generation layer (PDF, Excel) built on top of Granit.Templating. Provides
`IDocumentGenerator`, `IDocumentRenderer`, and `DocumentTemplateType`. Concrete renderers
(PuppeteerSharp, ClosedXML) live in separate packages.

Part of the [granit](https://granit-fx.dev) framework.

## Installation

```bash
dotnet add package Granit.DocumentGeneration
```

## Dependencies

- `Granit.Templating`
