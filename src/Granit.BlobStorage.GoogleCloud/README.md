# Granit.BlobStorage.GoogleCloud

Google Cloud Storage provider for `Granit.BlobStorage`. Registered as Keyed Service with key `"GoogleCloud"` for multi-provider resolution.

Part of the [granit](https://granit-fx.dev) framework.

## Installation

```bash
dotnet add package Granit.BlobStorage.GoogleCloud
```

## Dependencies

- `Granit.BlobStorage`
