# Granit.BlobStorage.Proxy

Proxy endpoint implementation for `Granit.BlobStorage`. Provides ephemeral
token-based upload/download URLs for server-side storage providers (FileSystem,
Database) that cannot generate native pre-signed URLs.

Part of the [granit](https://granit-fx.dev) framework.

## Installation

```bash
dotnet add package Granit.BlobStorage.Proxy
```

## Dependencies

- `Granit.BlobStorage`
