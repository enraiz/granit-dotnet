# Granit.Notifications.Sms.AwsSns

AWS SNS provider for `Granit.Notifications.Sms`. Registered as Keyed Service with key `"AwsSns"` for multi-provider resolution.

Part of the [granit](https://granit-fx.dev) framework.

## Installation

```bash
dotnet add package Granit.Notifications.Sms.AwsSns
```

## Dependencies

- `Granit.Notifications.Sms`
