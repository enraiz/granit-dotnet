# Granit.Workflow.Notifications

Approval notification bridge for `Granit.Workflow`. Routes approval requests to
designated approvers via `Granit.Notifications`. Provides `IApproverResolver` for
pluggable approver resolution.

Part of the [granit](https://granit-fx.dev) framework.

## Installation

```bash
dotnet add package Granit.Workflow.Notifications
```

## Dependencies

- `Granit.Authorization`
- `Granit.Identity`
- `Granit.Notifications`
- `Granit.Workflow`
