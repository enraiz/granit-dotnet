# Granit.DocumentGeneration.Excel

Excel document generation for Granit via ClosedXML. Provides `ClosedXmlTemplateEngine`,
which fills XLSX templates with a data model and returns binary output — no HTML
intermediate step required.

Part of the [granit](https://granit-fx.dev) framework.

## Installation

```bash
dotnet add package Granit.DocumentGeneration.Excel
```

## Dependencies

- `Granit.Templating`
