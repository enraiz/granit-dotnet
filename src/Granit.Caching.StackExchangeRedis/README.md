# Granit.Caching.StackExchangeRedis

Redis implementation for Granit.Caching using StackExchange.Redis.

Part of the [granit](https://granit-fx.dev) framework.

## Installation

```bash
dotnet add package Granit.Caching.StackExchangeRedis
```
