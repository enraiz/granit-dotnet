# Granit.DataImport.Excel

Excel file parser for the Granit DataImport pipeline, backed by
[Sylvan.Data.Excel](https://github.com/MarkPflug/Sylvan.Data.Excel).
Supports `.xlsx`, `.xls` and `.xlsb` formats via streaming `ExcelDataReader`.
Implements `IFileParser` from `Granit.DataImport`.

Part of the [granit](https://gitlab.digitaldynamics.be/digital-dynamics/granit-dotnet) framework.

## Installation

```bash
dotnet add package Granit.DataImport.Excel
```
