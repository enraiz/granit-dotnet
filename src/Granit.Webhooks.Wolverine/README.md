# Granit.Webhooks.Wolverine

Wolverine integration for the Granit webhook engine. Replaces the default
in-process channel dispatch with durable outbox-backed delivery via `IMessageBus`.

Part of the [granit](https://granit-fx.dev) framework.

## Installation

```bash
dotnet add package Granit.Webhooks.Wolverine
```

## Dependencies

- `Granit.Webhooks`
- `Granit.Wolverine`
