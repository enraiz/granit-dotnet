# Granit.ExceptionHandling

Centralized exception handling for Granit APIs. RFC 7807 Problem Details, chain of responsibility HTTP mapping, HDS 5xx masking in production, and systematic OTEL traceId.

Part of the [granit](https://gitlab.digitaldynamics.be/digital-dynamics/granit-dotnet) framework.

## Installation

```bash
dotnet add package Granit.ExceptionHandling
```
