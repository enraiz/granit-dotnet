# Granit.Notifications.Wolverine

Wolverine integration for the Granit notification engine. Replaces the default
in-process channel dispatch with durable outbox-backed delivery via `IMessageBus`.

Part of the [granit](https://granit-fx.dev) framework.

## Installation

```bash
dotnet add package Granit.Notifications.Wolverine
```

## Dependencies

- `Granit.Notifications`
- `Granit.Wolverine`
