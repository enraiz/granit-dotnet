# Granit.Identity.EntraId

Microsoft Entra ID (Azure AD) implementation of `IIdentityProvider` for Granit. Manages users, App Roles, groups, and sessions via the Microsoft Graph API v1.0.

Part of the [granit](https://granit-fx.dev) framework.

## Installation

```bash
dotnet add package Granit.Identity.EntraId
```

## Dependencies

- `Granit.Identity`
- `Granit.Timing`
