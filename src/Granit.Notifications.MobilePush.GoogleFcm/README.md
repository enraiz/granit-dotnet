# Granit.Notifications.MobilePush.GoogleFcm

Firebase Cloud Messaging (FCM) provider for `Granit.Notifications.MobilePush`. Sends push notifications via FCM HTTP v1 API with automatic token invalidation cleanup.

Part of the [granit](https://granit-fx.dev) framework.

## Installation

```bash
dotnet add package Granit.Notifications.MobilePush.GoogleFcm
```

## Dependencies

- `Granit.Notifications.MobilePush`
