# Guides

Cette section propose des tutoriels pas-à-pas pour prendre en main le framework Granit.

## Prérequis

- **.NET 10 SDK** installé ([dotnet.microsoft.com](https://dotnet.microsoft.com/download))
- **PostgreSQL 16+** (ou Docker : `docker run -p 5432:5432 -e POSTGRES_PASSWORD=dev postgres:16`)
- Familiarité avec C# et ASP.NET Core
